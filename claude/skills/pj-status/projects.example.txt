# pj-status の対象プロジェクト(ひな形)
#
# このファイルを同じフォルダに projects.txt としてコピーし、そちらに対象を書く。
# projects.txt はパスに個人の環境が含まれ、PC ごとに内容も違うので git 管理しない(.gitignore 済み)。
#
# 1行に1つ、プロジェクトのディレクトリのパスを書く(~ はホームディレクトリに展開される)。
# 「#」以降はコメント。上から書いた順に表示される。
#
# バックログ(~/.claude/backlog-data/<プロジェクト名>.md)の名前は、
# リモート origin のリポジトリ名 → git のトップディレクトリ名 → ディレクトリ名 の順に探す。
# 名前が合わない場合は「パス | バックログ名」の形で明示できる。
#
# 例:
# ~/work/app-a
# ~/work/tool-b | tool-b-backlog
