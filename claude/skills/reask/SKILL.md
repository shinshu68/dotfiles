# reask: 誤選択した選択肢の再提示

ユーザーはClaudeが出した選択肢を誤って選び、それに気づいて処理を止めた状態でこのスキルを呼び出す。目的は、**さっきと同じ選択肢をもう一度出して、正しく選び直してもらうこと**。ユーザーはすでに選択肢の内容を一度見ているので、内容が変わると「どれを選ぶつもりだったか」が分からなくなる。だから再提示は「元と同じもの」であることが何より大事。

## 手順

### 1. 対象の選択肢を特定する

会話をさかのぼり、ユーザーが最後に回答した選択肢を探す。対象は次の2種類。

- **質問カード** (AskUserQuestion ツールで出した、クリックで選ぶ選択肢)
- **文章中の番号付き候補** (「## 候補1」「候補2」…、「A案/B案」、「1. 〜 2. 〜」のように、Claudeが本文で並べてユーザーに選ばせたもの)

ユーザーが「2つ前の質問」「コミットメッセージの候補」のように対象を指定していれば、それに従う。指定がなければ、直近でユーザーが選んだものを対象にする。

選択肢が見つからない場合は、その旨を一言伝え、どの選択をやり直したいか聞く。

### 2. 誤った選択のあとに実行してしまった作業を確認し、報告する

誤った選択を受けて、止められるまでの間にClaudeが何かを実行していないか確認する (ファイルの作成・編集、コマンド実行、コミット、外部への送信など)。

- 実行済みの作業があれば、**何をどこまでやったか**を短く報告する (例:「誤った選択 (B案) を受けて、`config.yml` の編集まで実行済みです」)。
- この時点では元に戻さない。選び直した結果によって、そのまま活かせることもあるため、判断は選び直したあとに行う。
- 読み取りだけで何も変更していなければ、報告は省略してよい。

### 3. 同じ選択肢を再提示する

誤った選択は**無効**として扱い、その回答を前提にしない。そのうえで、元の選択肢を**そのまま**再提示する。

**質問カードの場合**: AskUserQuestion を元と同じ内容で呼び直す。

- 質問文・ヘッダー・選択肢のラベル・説明文・並び順・複数選択の可否・「(Recommended)」の付け方まで、元の呼び出しと同じにする。
- 1枚のカードに複数の質問があった場合は、原則としてカード全体を出し直す (どの質問を間違えたかユーザーが言っていれば、その質問だけでもよい)。
- 誤った選択で得た情報をもとに選択肢を書き換えたり、増減させたりしない。改善したくなっても、それは選び直してもらったあとに提案する。

**文章中の番号付き候補の場合**: 元の候補を、番号・本文ともに一字一句同じ形で再掲し、どれにするか選んでもらう。要約したり書き直したりしない (例えば commit-suggest の候補なら、`## 候補1` 以下をそのまま貼り直す)。

再提示の前置きは一言でよい (例:「さっきの選択肢をもう一度出します」)。「本当に選び直しますか？」のような確認はしない。ユーザーはすでに選び直すと決めてこのスキルを呼んでいる。

AskUserQuestion が使えない環境では、同じ内容を文章で番号付きにして提示する。

### 4. 選び直したあとの進め方

新しい選択に従って作業を進める。手順2で報告した実行済みの作業があれば、ここで扱いを決める。

- 新しい選択と矛盾する変更 (別の案の内容でファイルを書き換えた、など) は、元に戻してから新しい選択で進める。何を戻したかを一言伝える。
- 新しい選択でもそのまま使える作業は、やり直さずに活かす。
- 元に戻せない操作 (push済みのコミット、送信済みのメッセージなど) が含まれていた場合は、勝手に対処せず、状況を伝えてどうするかユーザーに確認する。

## 例

**例1 (質問カード)**

状況: Claudeが「コマンド名はどれにしますか？」(/reask・/reselect・/retry-choice) と質問カードを出し、ユーザーが誤って /reselect を選んだ。Claudeはまだ何も書き込んでいない段階でユーザーが止めた。

ユーザー: `/reask`

Claude: 「さっきの選択肢をもう一度出します。」→ 元と同じ質問・同じ3つの選択肢・同じ説明文・同じ (Recommended) で AskUserQuestion を呼び直す。

**例2 (番号付き候補・作業途中)**

状況: Claudeが「## 候補1」〜「## 候補3」のコミットメッセージ案を出し、ユーザーが「2で」と答えた。Claudeが候補2でコミットした直後にユーザーが止めた。

ユーザー: 「間違えた、3にしたかった。もう一回候補出して」

Claude: 「誤った選択 (候補2) を受けて、候補2のメッセージでコミットまで実行済みです (まだpushはしていません)。さっきの候補をもう一度出します。」→ 候補1〜3を元のまま再掲。ユーザーが候補3を選んだら、直前のコミットのメッセージを候補3に修正してよいか確認したうえで進める。
