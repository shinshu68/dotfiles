# バックログ一覧表示スキル (/backlog-list)

`/backlog` スキルが管理する `backlog.md` を読み取り専用で表示するための、コマンド専用スキル。ファイルは一切変更しない。

## 対象ファイルの特定

`/backlog` スキルと同じ場所・同じ命名規則を使う。

1. 現在の作業ディレクトリ名(gitリポジトリならその名前を優先)をプロジェクト名とする。
2. 対象ファイルは `~/.claude/backlog-data/<プロジェクト名>.md`。
3. ファイルが存在しない場合は、その旨をユーザーに伝える(例:「このプロジェクトのバックログはまだ作成されていません。`/backlog` でタスクを追加すると作成されます」)。新規作成はしない。
4. プロジェクト名が紛らわしい場合は、どのプロジェクトのバックログを見るかユーザーに確認する。
## 表示フォーマット

`backlog.md` は以下の構造を持つ(詳細は `/backlog` スキル参照):

- セクション: 進行中 / 未着手 / 完了
- 各タスク行: `- [ ] **#ID** \`優先度:X\` タイトル` (完了は `[x]`)
- 任意で `>` の詳細メモ
`/backlog-list` はこれを次の形式で会話内に表示する。ファイルは書き換えない。

**デフォルト(完了を含めない場合)**:

```
## バックログ一覧(<プロジェクト名>)

**件数サマリ**: 進行中 X件 / 未着手 Y件 / 完了 Z件(非表示) (合計 N件)

### 進行中
- #004 [優先度:高] タスクのタイトル

### 未着手
- #002 [優先度:中] 別のタスクのタイトル
- #003 [優先度:低] さらに別のタスク
- #005 [優先度:未設定] 優先度をまだ決めていないタスク

(完了 Z件は非表示。表示するには「/backlog-list 完了も」のように伝えてください)
```

**完了を含める場合**(下記「完了項目の表示条件」を満たしたとき):

```
## バックログ一覧(<プロジェクト名>)

**件数サマリ**: 進行中 X件 / 未着手 Y件 / 完了 Z件 (合計 N件)

### 進行中
- #004 [優先度:高] タスクのタイトル

### 未着手
- #002 [優先度:中] 別のタスクのタイトル
- #003 [優先度:低] さらに別のタスク
- #005 [優先度:未設定] 優先度をまだ決めていないタスク

### 完了
- #001 [優先度:中] 完了したタスク
```

### 完了項目の表示条件

- **デフォルトでは「完了」セクションは表示しない。** タスクが増えてくると一覧が見づらくなるため。
- 件数サマリには常に完了件数を含める(非表示であることが分かるよう「(非表示)」等を添える)ので、件数自体は把握できるようにする。
- 完了項目を表示するのは、ユーザーが明示的に指示したときだけ。例:「/backlog-list 完了も」「/backlog-list 全部」「/backlog-list すべて表示」のように、完了・全部・すべてなどを含む指示があった場合。
- 単に「/backlog-list」とだけ書かれている場合は、完了なしのデフォルト表示にする。
ルール:
- 件数サマリは各セクションのタスク数と合計を必ず先頭に示す(完了が非表示でも件数は出す)。
- 各セクションは元ファイルの並び順(優先度順→ID順、未設定は最後)をそのまま踏襲する。並べ替え・整形の都合で順序を変えない。
- 表示対象のセクションにタスクが0件でも見出しと「(なし)」を残し、空であることが分かるようにする。
- 詳細メモ(`>` 行)は一覧では省略してよい(タイトルと優先度のみで見通しを良くする)。ユーザーが特定タスクの詳細を尋ねたら、そのタスクのメモを個別に伝える。
- チェックボックスの `[ ]`/`[x]` はそのまま反映せず、セクション名(進行中/未着手/完了)で状態を表現する。
## 進め方

1. 対象の `backlog.md` パスを特定する(上記「対象ファイルの特定」)。
2. ファイルを読み込む。存在しなければユーザーに伝えて終了する。
3. 各セクションのタスク数を数え、件数サマリを作る。
4. ユーザーの指示に「完了も」「全部」「すべて」等が含まれるか確認し、完了セクションを表示するかどうかを判断する(上記「完了項目の表示条件」)。
5. 上記フォーマットで会話内に表示する。ファイルへの書き込みは一切行わない。
6. 表示後にユーザーが更新・追加・並べ替え等を依頼してきたら、`/backlog` スキルの操作範囲であることを伝えてそちらに委ねる(このスキル自身では変更しない)。
