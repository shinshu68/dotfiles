# 個人設定

## 言語設定
- 全ての応答は日本語で行う

## 応答スタイル
- ユーザーに実行してほしいコマンドは、1コマンドずつ個別のコードブロックで示し、そのままコピーして実行できるようにする

## 環境
- WSL2 (Ubuntu) + fish shell。シェルコマンドは fish で動く書き方を優先する

## Git 運用
- ブランチは develop から切る。master/develop へ直接コミットしない
- コミットメッセージは gitmoji + 日本語
- 1作業ごとにコミットする運用。複数の作業の変更を1つのコミットにまとめず、1つの作業が終わったら次の作業に進む前にコミットを挟む

## 全プロジェクト共通の注意点
- [2026-09-23] スキルが参照するスクリプトが見つからない場合、ルートディレクトリからfindで探し回らない。スキルのベースディレクトリ（呼び出し時に示される「Base directory for this skill: ...」）を起点に確認し、それでも見つからなければ見つからなかった旨をユーザーに伝えて止まる。
- [2026-09-24] PRのタイトル・本文には、ローカルで管理しているバックログ・タスクのID（#001など）やその言及を書かない。GitHubと紐づいていない情報は読み手に意味がなく、GitHubのIssue/PR番号とも紛らわしいため、変更の背景は内容そのもので説明する。
